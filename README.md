# YaKit-绘界

YaKit-绘界是 YaKit 系列的 SillyTavern 地图扩展，当前可预览地图主界面和设置页。

## 功能特性

- 从地图图标入口打开绘界。
- 沿用 YaKit-纪实的圆角卡片、设置分组和轻量动效。
- 桌面使用更大的主窗口，手机自动适应屏幕。
- 地图使用固定卡片，地图与设置页共用窗口大小及“地图图标 + YaKit-绘界”标题栏。
- 提供林系风、跟随酒馆、浅色、深色主题。
- 导航栏支持自动、上方、下方：自动时电脑显示上方文字导航，手机和平板显示下方图标导航。

## 安装方法

安装后，可直接从酒馆扩展菜单打开“绘界”。

1. 在酒馆扩展页安装 [YaKit-Chat](https://github.com/git-yafaya/ST-YaKit-chat)。
2. 在同一安装范围内安装 [YaKit-绘界](https://github.com/git-yafaya/ST-YaKit-map)，使两个扩展处于同级目录。
3. 刷新酒馆，打开输入框附近的扩展菜单。
4. 点击带地图图标的“绘界”，即可看到地图主界面。

请保留两个扩展原有的目录名称；绘界会直接复用纪实的公共界面文件。

## 使用说明

1. 在扩展菜单中点击地图图标旁的“绘界”，地图区域显示“暂无地图”。
2. 点击导航栏的“地图”或“设置”文字、对应图标切换页面。
3. 在设置页展开“界面设置”，选择主题；导航栏样式默认“自动”，也可在同一排选项中选择“上方”或“下方”，调整后即时生效。
4. 展开“副 API”或“提示词”可查看对应的入口布局；这两组目前仅供界面预览。
5. 点击标题栏右侧的关闭按钮、窗口外的遮罩，或按 `Esc` 关闭；再次打开回到地图页。

主题、导航位置和设置分组的展开状态在当前酒馆页面内保留；刷新后恢复林系风、自动导航和收起状态；手动选择上方或下方会覆盖自动位置，上方显示文字，下方显示图标。

## 兼容性

最低支持 SillyTavern `1.14.0`，与所复用的 YaKit-Chat 保持相同的最低版本要求。需同时安装 YaKit-Chat `0.0.17` 或更新版本，以提供自动导航识别；浏览器需支持原生弹窗和弹出选项菜单。
